# Vertex Snap

В Edit Mode откройте Placement → Vertex Snap. Выберите объект или группу и используйте Move Gizmo.

1. Удерживая **V**, щёлкните ЛКМ по нужной вершине выделенного Mesh. Можно выбрать вершину дочернего Mesh, когда выделен корень Prefab/иерархии. Жёлтый маркер обозначает источник.
2. Отпустите V и потяните Move Gizmo к вершине другого Mesh. Голубой маркер обозначает цель. Источник совмещается с ней в мировых координатах.
3. Отпустите ЛКМ для подтверждения. **Escape** отменяет весь жест. Операция занимает один шаг Undo/Redo.

Меняются только позиции. Поворот и масштаб сохраняются; группа сдвигается целиком, Parent + Child не перемещаются дважды. Selection Lock не мешает Gizmo или явному выбору исходной вершины.

Vertex Snap временно перекрывает Grid Snap при Move, не меняя его настройку. Surface Snap/Align to Normal остаются инструментами размещения и не поворачивают объект при привязке вершин. Alt+Drag сохраняет обычное дублирование без Vertex Snap; для копии выберите источник заново.

Для цели учитываются Selection Filters, Isolation и видимость Mesh. Собственное перемещаемое поддерево исключается. Порог выбора — 12 экранных единиц с учётом DPI; выбранная цель удерживается до 18 для устойчивости. Окклюзия по пикселям не проверяется.

Доступны только уже загруженные CPU Mesh. Инструмент не запускает загрузку; при отсутствии геометрии показывает подсказку. Локальные bounds кэшируются по ресурсу и версии, вершины перебираются только у Mesh, чьи проекции bounds находятся возле курсора.

В Play инструмент отключён. После смены сцены, Play/Stop, замены ресурса или исключения исходного объекта из выделения исходную вершину нужно выбрать заново.
