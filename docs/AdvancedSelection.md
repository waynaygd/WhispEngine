# Advanced Selection

В Edit Mode потяните ЛКМ из пустой области Viewport. Рамка начинается после стандартного порога движения мыши.

- Без модификатора рамка заменяет выделение; Ctrl (или Shift) добавляет; Alt вычитает. Режим фиксируется при нажатии. Ctrl+Click сохраняет переключение Entity, Alt+Drag на Gizmo сохраняет дублирование.
- Выбираются Entity, чьи проекции bounds хотя бы частично пересекают рамку, включая закрытые другими объектами. Учитываются World Transform, поворот, отрицательный scale, смещённый pivot и ближняя/дальняя плоскости камеры. Фильтры и Isolation действуют как при обычном выборе. Дочерний объект выбирается отдельно от Parent.
- У Mesh используются bounds загруженной геометрии, у Collider и Player Start — их размеры; у пустых объектов, глобального Fog и источников света — область редакторского маркера. Незагруженные Mesh пропускаются.
- В меню View есть Selection Lock с иконкой замка. Он защищает набор от кликов в Viewport/Hierarchy и рамки. Gizmo, Inspector, Undo/Redo, Create и Paste продолжают работать. Новая сцена снимает Lock; удалённые ID очищаются.
- Escape отменяет рамку. Смена сцены, Play, потеря фокуса, смена размеров Viewport/F11 или начало Drag-and-Drop также отменяют текущий жест. В Play рамка отключена, как и существующий выбор в Viewport.

Это выделение по экранной проекции bounds, без проверки видимости отдельных пикселей.
